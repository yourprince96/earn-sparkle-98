# Earning Buddy

Build a perfect Task Earning App for mobile with Firebase.



User App Features:

1. Login/Signup with email

2. Home page with 3 task types - Watch Ad, Visit Website, Daily Spin. Each task shows reward amount.

3. When user clicks a task, open a new page with Start button, 30 second timer, and Claim button. Touch must work 100%

4. Wallet page - show total balance, today's earning, total withdrawn

5. Withdraw page - Bkash, Nagad, with minimum 100 Taka

6. Refer page - show refer code and earning

7. Bottom navigation - Home, Wallet, Refer, Profile - all must be touchable



Admin Panel:

- Admin login: admin@gmail.com / admin123

- Dashboard - total users, total pending withdraws

- All Tasks management - add, edit, delete task with reward amount

- Withdraw request approve/reject

- User list and block option



Design: Modern, colorful, no bug, everything touchable.
